# Code of conduct

Assume competence and good faith. Criticise the data, not the contributor, and
respect attribution even when it is inconvenient.

Harassment, removing attribution, and submitting data of unknown provenance are
not tolerated. Report problems privately to
[@thepeternemec](https://github.com/thepeternemec).

The full expectations are in [CONTRIBUTING.md](CONTRIBUTING.md#conduct).
